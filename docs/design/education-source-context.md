# 教研数据来源上下文

教研场景不只保存一个来源名称。每个来源同时声明教师可见范围、可执行能力、首选 Skill、官方域名和执行约束。创建 Hermes Goal 时，这些信息会作为“数据来源执行上下文”注入，避免远程 Agent 只看到 `source:*` 标识后自行猜测。

## 当前来源

| 来源 | 教材课程目录 | 学科知识点树 | 执行方式 |
| --- | --- | --- | --- |
| 学科网 | 支持 | 支持 | `xueke-textbook-knowledge-tree` |
| 空中课堂 | 支持 | 暂不声明支持 | `shanghai-smartedu-catalog`，优先调用 `indexPanel`、`point/tree` |
| 国家智慧教育平台 | 不绑定该场景 | 暂不声明支持 | `national-smartedu-resource-catalog`，绑定独立“国家平台教材资源发现”场景，交付官方资源导航 |
| 已配置教材来源 | 按实例实际能力 | 按实例实际能力 | 运行时读取当前 Hermes 配置 |

## 运行时规则

- 数据来源中心通过当前 Hermes Profile 的 Skill 清单计算可用状态。
- 任务启动前再次检查首选 Skill；Skill 缺失或禁用时停止创建会话并显示缺失名称。
- 国家平台 Skill 只负责官方教材、同步课程和专题资源导航；只有官方响应明确提供层级时才保留该层级，不把筛选标签冒充课程树。
- 结构化场景的确认页产生 `SCENE_INTAKE_CONFIRMED`。Skill 可自动完成同范围的内部目的令牌校验，但真实版本候选仍需用户选择。
- 教材课程树与学科知识点树保持两个独立输出方向，不按节点名称推测映射。
- 教材版本、学期或平台分区存在多个真实候选时，由 Hermes 请求用户确认。
